# Security Policy

This code is meant to teach Rust and AI development concepts. It is not intended for production use and is supported
strictly on a **best-effort basis**.

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.** Even though this is an educational project,
public exploits can put users at risk if they have adapted this code.

Instead, please report vulnerabilities privately using the **"Report a vulnerability"** button under the **Security**
tab of this repository.

### Please Include
* A detailed description of the vulnerability.
* Step-by-step instructions to reproduce the issue (including PoC scripts or payloads if applicable).
* The potential impact or exploitability of the bug.

## Response Process

Because this is a personal educational project, there is no formal commitment or timeline to fix reported
issues. However, I highly value the opportunity to learn from your findings and improve the code when time permits.
